# Ciencias Naturales Interactivas

Juego educativo interactivo con detección de manos (MediaPipe). Dos jugadores clasifican tarjetas por gestos en diferentes temas de Ciencias Naturales.

## Temas disponibles
- Propagación de Plantas
- Reino Animal
- Ecosistemas del Mundo
- Sistemas del Cuerpo Humano

## Cómo usar
Abrir `index.html` con un servidor local (p.ej. Live Server en VSCode).
